# Support

Thanks for using Albion Online Loot Logger!

## Before asking for help

1. Confirm you are using a recent copy of the project.
2. Refresh the page and try a small test CSV.
3. Check that the required `item_id` and `item_name` columns exist and are spelled exactly as shown.
4. If item images are missing, check your internet connection and whether the external image service is reachable.
5. Open your browser developer console and note any relevant error messages, but remove tokens, personal details, and private data before sharing.

## Where to ask

- **Bug reports:** Open a GitHub issue using the Bug report template.
- **Feature ideas:** Open a GitHub issue using the Feature request template.
- **Code or documentation contributions:** See `CONTRIBUTING.md` and open a pull request.
- **Security issues:** Follow `SECURITY.md`; do not post exploit details publicly.

A public GitHub repository URL, Discussions link, and direct support contact have not been supplied for this documentation package. Add the real project links here before publishing. Do not invent a contact address.

## When reporting a problem

Include the project version or commit, browser and operating system, steps to reproduce, expected result, actual result, and a small synthetic CSV example if needed. Do not attach real loot exports or identifiable player/guild data unless you have permission and have considered the privacy impact.
